# 🧠 16Personalities-style type

An original approximation of the 16Personalities model (5 dimensions → a code like `INTJ-A`). Do not copy the official site's items.

## Dimensions

| Dimension | Poles | Letter |
|---|---|---|
| Mind | Introverted ↔ Extraverted | I / E |
| Energy | Intuitive ↔ Observant | N / S |
| Nature | Thinking ↔ Feeling | T / F |
| Tactics | Judging ↔ Prospecting | J / P |
| Identity | Assertive ↔ Turbulent | -A / -T |

## Questions

- Quick: **3 per dimension = 15**. In depth: **8 per dimension = 40**.
- Statements on an agreement scale: A) Strongly agree · B) Agree · C) Neutral · D) Disagree · E) Strongly disagree (score +2 … −2). If the question tool allows only 4 options, drop "Neutral" (see SKILL.md).
- Balance keying: about half the items per dimension keyed toward each pole, to cancel acquiescence bias.
- Interleave dimensions within a batch; never cluster one dimension.
- Write concrete, behavioural statements ("After a long party I need a quiet day to recover"), not abstract self-labels ("I am an introvert").

## Scoring

Per dimension: sum, normalise to a 50–100% lean toward the winning pole (show both percentages). Within ±5% of the midpoint → mark as "borderline" and use cross-test evidence (SKILL.md) to break the tie, saying so.

## Results

- Type code, name (Architect, Logician, Commander, Debater, Advocate, Mediator, Protagonist, Campaigner, Logistician, Defender, Executive, Consul, Virtuoso, Adventurer, Entrepreneur, Entertainer), role group (Analysts / Diplomats / Sentinels / Explorers), strategy (Confident Individualism, People Mastery, Constant Improvement, Social Engagement).
- Dimension bars, strengths, blind spots, how they likely work/learn/communicate, a "runner-up type" if any dimension was borderline.
- **Figures**: 6 **current** (living or active) public figures and 6 **historical** figures commonly typed the same way. #1 of each list featured with a paragraph; #2–6 one line each. Note once that typings of real people are speculative.
- A fictional-characters line is welcome (ties back to the HP/PJ results).
